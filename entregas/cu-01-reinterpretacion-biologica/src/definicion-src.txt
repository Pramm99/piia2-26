Definición de la estructura del código fuente
==============================================

El código del pipeline no vive en esta carpeta src/, sino en codigo/, dentro de la carpeta del
equipo (entregas/cu-01-reinterpretacion-biologica/codigo/). Este fichero describe esa estructura:
qué módulos existen, siguiendo ARCHITECTURE.md (los números entre corchetes son los componentes
de su diagrama). Hay una carpeta por fase. Estado a 2026-11-11.

Leyenda: (hecho) implementado · (en parte) implementado con cambios pendientes ·
         (previsto) pendiente; el nombre del fichero es una propuesta.

codigo/
├── fase1_ingesta/                 # FASE 1 · Ingesta (spec descarga-evidencias-go-pmc, ADR-002)
│   │                              #   Se ejecuta con: python codigo/fase1_ingesta/main.py
│   ├── main.py                    #   (hecho) Orquesta la Fase 1 en orden.
│   ├── config.py                  #   (hecho) Rutas (entrada: los Excels de tools_cimus/), URLs, umbrales y opciones
│   │                              #   de filtrado; lee NCBI_EMAIL y NCBI_API_KEY de codigo/.env.
│   ├── red.py                     #   (hecho) Sesión HTTP con reintentos, descarga atómica del OBO y el GAF y
│   │                              #   aviso de progreso (porcentaje y tiempo) de las descargas largas.
│   ├── entrada_excel.py           #   (hecho) [1] Lectura de las dos listas de rutas (.xlsx o .csv) -> pares (gen,
│   │                              #   ruta) con Estado_Original; ValueError si falta una columna, antes de la red.
│   ├── grafo_go.py                #   (hecho) [2] Grafo GO, propagación al subárbol con profundidad y signo.
│   ├── inmunoglobulinas.py        #   (hecho) [3] Genes de inmunoglobulina (HGNC) -> hoja Inmunoglobulinas, neutros.
│   ├── cruce_gaf.py               #   (hecho) [4] Cruce con el GAF -> evidencias con PMID y tabla de anotaciones.
│   ├── polaridad.py               #   (hecho) [5] Triaje del signo GO (Destino) y cierre de los pares sin_evidencia.
│   ├── pmid_externos.py           #   (hecho) [6] PMIDs de GeneRIF y Europe PMC para los pares sin abstract del GAF.
│   ├── relevancia.py              #   (hecho) [6] Mención del gen y coincidencia gen-proceso en la misma frase
│   │                              #   (también la usa la Fase 2 para el filtro de mención).
│   ├── fuentes/                   #   (hecho) [3, 6] Clientes de las fuentes externas:
│   │   ├── generif.py             #     MyGene.info (alias, nombre y GeneRIF).
│   │   ├── europepmc.py           #     Búsqueda dirigida en Europe PMC.
│   │   ├── uniprot.py             #     Función de las inmunoglobulinas (UniProt Swiss-Prot).
│   │   └── cache.py               #     Escritura atómica de las cachés JSON.
│   ├── abstracts.py               #   (hecho) [7] Europe PMC + NCBI con caché de abstracts en crudo y limpiar_texto.
│   ├── salida.py                  #   (hecho) [8] Embudo por consola y Excel de la Fase 1 (7 hojas).
│   └── fase1_dataset_abstracts.xlsx  # Salida de la Fase 1 y entrada de la Fase 2 (no se versiona).
│
├── fase2_inferencia/              # FASE 2 · Inferencia (specs limpieza e inferencia-llm, ADR-003/004/005)
│   │                              #   Se ejecuta desde codigo/ con: python -m fase2_inferencia ejecutar
│   ├── esquema.py                 #   (hecho) Tipos inmutables (CasoProceso, PromptLLM, PromptLista), esquemas
│   │                              #   JSON de la respuesta, motivos y umbral (UMBRAL_VEREDICTO = 80).
│   ├── lectura.py                 #   (hecho) [9] Hoja Con_abstract de las dos listas -> filas que van al LLM.
│   ├── limpieza.py                #   (hecho) [9] Limpieza conservadora, forma de comparación y frases numeradas.
│   ├── casos.py                   #   (hecho) [10] Filas -> preguntas (gen, PMID, proceso núcleo) y filtro de
│   │                              #   mención del gen (no_menciona_gen).
│   ├── proceso.py                 #   (hecho) [10] Proceso núcleo de un término GO y signo del camino hasta la ruta.
│   ├── prompt.py                  #   (hecho) [11] Prompt único (veredicto obligado), enviado por gen y troceado
│   │                              #   según el presupuesto por llamada.
│   ├── cliente.py                 #   (hecho) [12] Conector único compatible con OpenAI (Gemini, Groq, Cerebras,
│   │                              #   Ollama), reintentos ante 408/429/5xx y cliente simulado para pruebas.
│   ├── ejecucion.py               #   (hecho) [12] Ejecución reanudable, revalidación y partición de salidas cortadas.
│   ├── registro.py                #   (hecho) [12] respuestas_llm.jsonl y llamadas_llm.jsonl (ADR-004).
│   ├── respuesta.py               #   (hecho) [13] Extracción del JSON, verificación de las citas y decisión de UNKNOWN.
│   ├── confianza.py               #   (hecho) [13] confianza_final (factores provisionales).
│   ├── resultados.py              #   (hecho) [14] Contraste entre modelos y con GO; fase2_resultados.xlsx.
│   ├── pipeline.py                #   (hecho) [14] Orquestación de la Fase 2 (ejecutar_fase2).
│   ├── _fase1.py                  #   (hecho) Puente hacia los módulos de la Fase 1.
│   └── __init__.py / __main__.py  #   (hecho) API del paquete, ejecución completa y demo por línea de comandos.
│
├── fase3_scoring/                 # FASE 3 · Scoring (spec scoring-net-pathway-score) [15]
│   │                              #   Se ejecuta desde codigo/ con: python -m fase3_scoring
│   ├── nps.py                     #   (hecho) Votos ponderados por artículo -> signo del par -> NPS de cada ruta;
│   │                              #   fase3_scoring.xlsx (Por_ruta, Por_par, Resumen).
│   ├── config.py                  #   (hecho) Pesos de contexto, minoría de conflicto y umbrales de lectura
│   │                              #   (provisionales).
│   └── __init__.py / __main__.py  #   (hecho) API del paquete y línea de comandos.
│
├── evaluacion/                    # BENCHMARK [16] (spec benchmark-gold-set, ADR-005)
│   ├── seleccionar_gold.py        #   (hecho) Rehace el gold set sobre una Fase 1 nueva sin volver a sortear.
│   ├── buscar_neutros.py          #   (hecho) Candidatos a caso neutro (dos listas) para ampliar el gold set.
│   ├── evaluar_gold.py            #   (hecho) Ejecución del benchmark e informe con IC, matriz y calibración.
│   ├── gold_casos.jsonl           #   (hecho) Selección del gold set (100 casos, 65 up y 35 down; no se enseña
│   │                              #   a los anotadores).
│   ├── plantilla_etiquetado.*     #   (hecho) Plantilla a ciegas (.jsonl versionado; .xlsx, con las columnas de la
│   │                              #   guía, incluidas confianza y nota, no se versiona).
│   ├── guia_etiquetado.md         #   (hecho) Guía de etiquetado a 4 clases.
│   ├── etiquetas/                 #   (hecho) Etiquetas del gold set (anotadores Claude a ciegas, doble etiqueta),
│   │                              #   con su SHA-256 y LEEME.md.
│   └── informe_gold.txt           # Informe del benchmark (Gemini y gpt-oss).
│
├── pytest.ini                     # Configuración de pytest (python -m pytest desde codigo/).
├── tests/                         # PRUEBAS (pytest, sin red ni claves)
│   ├── conftest.py                #   (hecho) Casos y respuestas de ejemplo comunes.
│   ├── test_limpieza.py           #   (hecho) Limpieza, forma de comparación, citas, frases y mención del gen.
│   ├── test_respuesta.py          #   (hecho) Validación de la respuesta, signo por ruta y listas.
│   ├── test_resultados.py         #   (hecho) Contraste con GO y entre modelos, y confianza_final.
│   ├── test_ejecucion.py          #   (hecho) Registro y ejecución reanudable con el cliente simulado.
│   ├── test_fase1.py              #   (hecho) Entrada, grafo GO, inmunoglobulinas, descarga simulada y .env.
│   ├── test_entrada.py            #   (hecho) Entrada .xlsx y .csv y validación de columnas.
│   ├── test_scoring.py            #   (hecho) Votos, signo del par, contribución y NPS.
│   ├── test_fase1_e2e.py          #   (hecho) Fase 1 completa sobre fixtures, sin red, y su paso por las Fases 2 y 3.
│   ├── test_cliente.py            #   (hecho) Conector LLM con HTTP simulado (reintentos, 429, errores de JSON).
│   ├── test_red.py                #   (hecho) Reintentos con espera exponencial y descarga atómica.
│   └── fixtures/                  #   OBO y GAF mínimos, listas de CIMUS y respuestas HTTP grabadas (texto, sin
│                                  #   Excels: los .xlsx de entrada se escriben en una carpeta temporal).
│
├── tools_cimus/                   # Material de CIMUS: Excels de rutas enriquecidas (los únicos .xlsx versionados)
│                                  #   y su script de análisis.
├── data/                          # Ficheros locales, ignorados por git (ADR-004):
│                                  #   go-basic.obo, goa_human.gaf.gz, cachés (cache_abstracts.json,
│                                  #   cache_mygene.json, cache_epmc_busquedas.json, cache_uniprot.json,
│                                  #   hgnc_inmunoglobulinas.json), respuestas_llm.jsonl, llamadas_llm.jsonl,
│                                  #   fase2_resultados.xlsx, fase3_scoring.xlsx y los registros del benchmark.
├── requirements.txt               # Dependencias de Python: requests, pandas, openpyxl (y pytest para las pruebas).
├── .env.example                   # Nombres de las claves (GEMINI_API_KEY, GROQ_API_KEY, CEREBRAS_API_KEY,
│                                  #   NCBI_EMAIL, NCBI_API_KEY), vacíos.
└── .env                           # Las claves reales. Solo en local: está en .gitignore y NUNCA se sube.

Eliminados (siguen en el historial de git):
  - ApiREST_OFICIAL.py             # Prototipo inicial contra AmiGO/GOlr (descartado en el ADR-002).
  - consultar_gen.py               # Primera versión de la Fase 2 con Groq y llama3-8b-8192; sustituida por cliente.py.
